# UserSim HTML talk artwork

Built-in ImageGen created the fictional archive scene and the icons using
generic descriptions. Quarto embeds the assets so the deck works offline.

- **Archive scene**. The prompt asked for a researcher at an archive desk with
  a highlighted historical book and two unlabeled dataset files on a laptop.
  It asked for brown ink outlines, colored-pencil fills, a warm cream
  background, and lavender, turquoise, and amber accents. The visual reference
  was the [published TREC RAG talk](https://npatta01.github.io/trec_rag_2026/reports/2026-trec-rag-talk.html).
- **Icons**. The prompt asked for isolated editorial icons with navy contours
  and teal, violet, and amber accents. The draft, edit, sent message, dialogue,
  and document search icons were cropped from the generated sheet and resized
  with their transparency preserved.
