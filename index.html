Simulating a researcher’s dataset search

We played the researcher in a conversation with the organizers’ dataset-search assistant. GPT-6 Luna drafted each researcher reply, then made one pass to edit the wording.

How the simulator works

Task 1 · Predict one reply

Given a researcher profile, search goal, and conversation prefix, the simulator predicts the next researcher message. Every case starts from its supplied history. The editor can repair unsupported claims about actions such as downloading a dataset.

Task 2 · Run the conversation

The simulator exchanges messages with the search assistant. Each draft includes a choice to continue or stop. The editor revises the text, and the runner sends the edited reply with the draft’s decision.

Preliminary organizer results

The November 4 release compares our submissions with human reference conversations. Jensen–Shannon divergence (JSD) measures the difference in the mix of dialogue acts, such as asking for clarification. Lower values mean a closer match.
